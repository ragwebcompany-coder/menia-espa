# Ιστοσελίδα — Μένια Καρανάσιου, Διαιτολόγος · Διατροφολόγος

Στατικός ιστότοπος (HTML/CSS/JS, χωρίς framework), παραγόμενος από generator.
Ίδια αρχιτεκτονική με το Dental Harmony Clinic· το περιεχόμενο και η παλέτα
είναι εξ ολοκλήρου νέα.

## Δομή

```
build/data.mjs     ← ΟΛΟ το περιεχόμενο & τα στοιχεία πελάτη (μοναδική πηγή αλήθειας)
build/build.mjs    ← ο generator (templates, SEO, schema.org, sitemap)
styles.css         ← σχεδίαση + προσβασιμότητα
main.js            ← μενού, φόρμα, widget προσβασιμότητας
assets/            ← εικόνες, αφίσα ΔΥΠΑ, σήμα προσβασιμότητας
*.html             ← ΠΑΡΑΓΟΜΕΝΑ — μην τα επεξεργάζεστε χειροκίνητα
```

## Παραγωγή

```bash
node build/build.mjs        # 28 σελίδες + sitemap.xml + robots.txt + favicon.svg
python3 -m http.server 8777 # τοπική προεπισκόπηση: http://localhost:8777
```

Ο generator προειδοποιεί για όσα στοιχεία πελάτη εκκρεμούν.

## ⚠ Εκκρεμή στοιχεία πελάτη

Όλα βρίσκονται στο `build/data.mjs` μέσα σε **[αγκύλες]**. Μετά τη συμπλήρωση,
τρέξτε ξανά `node build/build.mjs`.

| Πεδίο | Τι χρειάζεται |
|---|---|
| `BASE`, `email` | domain (π.χ. `meniadiatrofi.gr`) |
| `phoneDisplay`, `phoneIntl` | Τηλέφωνο |
| `street`, `area`, `city`, `region`, `postal` | Διεύθυνση γραφείου |
| `lat`, `lng` | Συντεταγμένες (τώρα δείχνουν Αθήνα — για το schema.org) |
| `instagram`, `facebook`, `tiktok`, `social` | Λογαριασμοί social |
| `portrait` | Φωτογραφία (~985 × 1060 px) στο `assets/`, αντί του `portrait.svg` |
| `BIO` | Έτη εμπειρίας, σπουδές, εξειδικεύσεις |
| `CREDS` | Πανεπιστήμιο & τίτλοι |
| `AREAS` | Περιοχές εξυπηρέτησης (slug με λατινικούς χαρακτήρες) |
| `wheelchairAccessible` | Αν ο χώρος είναι προσβάσιμος με αμαξίδιο (το δηλώνει η σελίδα προσβασιμότητας) |
| `hours` | Επιβεβαίωση ωραρίου |

Επιπλέον, ελέγξτε ότι τα κείμενα υπηρεσιών/άρθρων αντιστοιχούν σε ό,τι πράγματι
προσφέρει — αφαιρέστε όποια υπηρεσία δεν ισχύει από τον πίνακα `SERVICES`.

## Φόρμα επικοινωνίας

Χωρίς backend, η φόρμα ανοίγει το πρόγραμμα email του επισκέπτη με συμπληρωμένο
το μήνυμα (`data-mailto`). Για κανονική αποστολή από τον server, προσθέστε
`action="…"` στη φόρμα (στο `build.mjs`, `pageContact()`) — το JS τότε αφήνει τη
φόρμα να υποβληθεί κανονικά και κρατά μόνο το validation.

## Προσβασιμότητα — τι υλοποιήθηκε (EN 301 549 → WCAG 2.1 AA)

**Επίπεδο AA, όχι AAA.** Το AAA απαιτείται μόνο για ιστότοπους που απευθύνονται
*ειδικά* σε άτομα με αναπηρία. Εδώ πρόκειται για ιστότοπο διαιτολογικού γραφείου
προς το γενικό κοινό — η υπηρεσία διατροφής ΑμεΑ είναι μία από δέκα. Το
σκεπτικό τεκμηριώνεται ρητά στη `prosvasimotita.html`, ώστε να απαντά σε
ενδεχόμενο έλεγχο.

Πλήρες AAA δεν είναι ρεαλιστικά εφικτό εδώ: το 3.1.5 (επίπεδο ανάγνωσης) απαιτεί
γλώσσα κατώτερης δευτεροβάθμιας — ασύμβατο με ιατρική ορολογία — και το 1.4.9
(εικόνες κειμένου) προσκρούει στην υποχρεωτική αφίσα του φορέα. Πληρούνται όμως
δέκα άλλα κριτήρια AAA (καταγράφονται στη δήλωση).


**Πλοήγηση με πληκτρολόγιο (2.1.1, 2.1.2, 2.4.3, 2.4.7)**
- Όλα τα στοιχεία προσβάσιμα με `Tab` / `Enter` / `Space` / `Esc`, χωρίς παγίδευση.
- Δακτύλιος εστίασης 3px υψηλής αντίθεσης σε κάθε διαδραστικό στοιχείο.
- Σύνδεσμοι παράλειψης (περιεχόμενο, πλοήγηση, δήλωση προσβασιμότητας).
- Το μενού κινητού παίρνει `visibility: hidden` όταν κλείνει, ώστε η εστίαση να
  μη «χάνεται» εκτός οθόνης — το συχνότερο σφάλμα σε off-canvas μενού.
- Το υπομενού υπηρεσιών ανοίγει με `:focus-within`, όχι μόνο με hover.
- `Esc` κλείνει μενού/πάνελ και επαναφέρει την εστίαση στο κουμπί που τα άνοιξε.

**Εναλλακτικό κείμενο (1.1.1)**
- Περιγραφικό `alt` σε κάθε πληροφοριακή εικόνα· κενό `alt=""` στις διακοσμητικές.
- Η αφίσα ΔΥΠΑ έχει πλήρη μεταγραφή κειμένου σε `alt`, σε HTML στη σελίδα
  `chrimatodotisi.html`, και μέσα στο ίδιο το PDF (δες παρακάτω).
- Τα εικονίδια-γλυφικά είναι `aria-hidden="true"`.

**Χρωματική αντίθεση (1.4.3, 1.4.11)**
- Κάθε συνδυασμός κειμένου/φόντου ≥ 4.5:1 (επαληθευμένο υπολογιστικά).
- Περιγράμματα πεδίων φόρμας & κουμπιών ≥ 3:1 (γι' αυτό `--taupe`/`--olive`,
  όχι `--line`).
- Το `--sage` είναι **μόνο** διακοσμητικό — ποτέ για κείμενο.
- Η πληροφορία δεν βασίζεται μόνο στο χρώμα: σύνδεσμοι κειμένου υπογραμμισμένοι,
  σφάλματα φόρμας με γραπτό μήνυμα.
- Ο δακτύλιος εστίασης αλλάζει σε ανοιχτό χρώμα μέσα στο σκούρο footer και στην
  ταινία· με το κόκκινο θα είχε αντίθεση 1.63:1, δηλαδή θα ήταν αόρατος.
- Το κείμενο σώματος ξεπερνά και το κατώφλι 7:1 του AAA κριτηρίου 1.4.6.

**Σημασιολογική δομή (1.3.1, 2.4.6, 2.4.2)**
- `<header> <nav> <main> <article> <aside> <footer>`, μία `<h1>` ανά σελίδα,
  ιεραρχία h1→h6 χωρίς άλματα, μοναδικοί τίτλοι, `lang="el"`.
- Ετικέτες σε κάθε landmark πλοήγησης (`aria-label`).
- FAQ με native `<details>/<summary>` — προσβάσιμο εξ ορισμού.

**Μέγεθος γραμματοσειράς / zoom 200% (1.4.4, 1.4.10)**
- Όλα τα μεγέθη σε `rem`· καμία fluid τυπογραφία με `vw` (που συρρικνώνεται στο zoom).
- Breakpoints σε `em`, ώστε το layout να αναδιατάσσεται σωστά στο zoom.
- Αναδιάταξη σε πλάτος 320px χωρίς οριζόντια κύλιση.

**Κίνηση & χρόνος (2.2.2, 2.3.1)**
- Κουμπί παύσης στην κινούμενη ταινία κειμένου.
- `prefers-reduced-motion` σέβεται τις ρυθμίσεις συστήματος.
- Κανένα περιεχόμενο που αναβοσβήνει, κανένα χρονικό όριο.

**Φόρμες (3.3.1, 3.3.2, 3.3.3, 4.1.3)**
- Ορατή `<label>` για κάθε πεδίο, υποχρεωτικά και σε κείμενο.
- Σφάλματα με `aria-invalid`, `aria-describedby`, `role="alert"` και αυτόματη
  μεταφορά εστίασης στο πρώτο λανθασμένο πεδίο.

**Widget προσβασιμότητας**
Κουμπί κάτω δεξιά (το επίσημο σήμα): μέγεθος κειμένου 90–160%, υψηλή αντίθεση,
υπογράμμιση συνδέσμων, απενεργοποίηση κινήσεων. Οι ρυθμίσεις αποθηκεύονται στο
`localStorage` και εφαρμόζονται πριν την πρώτη ζωγραφική (χωρίς αναλαμπή).

**Δήλωση προσβασιμότητας**: `prosvasimotita.html` — απαραίτητη για ΕΣΠΑ/ΔΥΠΑ.

## ΔΥΠΑ / NextGenerationEU

- `chrimatodotisi.html`: αφίσα δημοσιότητας (εικόνα + PDF + πλήρες κείμενο σε HTML).
- Σήμα σε κάθε σελίδα, στο footer, μαζί με το σήμα προσβασιμότητας.

### Το PDF της αφίσας (non-web document)

Το αρχείο που παραδόθηκε ήταν outlined («Print To PDF»): **0 χαρακτήρες
εξαγώγιμου κειμένου**, δηλαδή εντελώς αδιάβαστο από screen reader — μη
συμμόρφωση με το EN 301 549, Κεφ. 10.

Το `build/make_accessible_pdf.py` παράγει προσβάσιμη εκδοχή:

```bash
python3 build/make_accessible_pdf.py "../poster scale up.pdf" assets/dypa-poster.pdf
```

| | πρωτότυπο | προσβάσιμο |
|---|---|---|
| Εξαγώγιμο κείμενο | 0 χαρ. | 668 χαρ. |
| Tagged (`/MarkInfo`, `StructTreeRoot`) | όχι | ναι — H1 + 4×P + Figure |
| `/Lang` | όχι | `el-GR` |
| Τίτλος εγγράφου + `DisplayDocTitle` | όχι | ναι |
| `/Alt` στην εικονογράφηση | όχι | ναι |
| Σειρά ανάγνωσης | — | κείμενο → εικόνα |
| Εικαστικό | — | **pixel-identical** (επαληθευμένο με σύγκριση render) |

Το πρωτότυπο διατηρείται ως `assets/dypa-poster-original.pdf` και είναι επίσης
διαθέσιμο προς λήψη, για λόγους τεκμηρίωσης προς τον φορέα.

**Για κάθε νέο PDF που θα ανέβει** ισχύει η ίδια απαίτηση: tagged, με γλώσσα,
τίτλο, σειρά ανάγνωσης και alt στις εικόνες — και το περιεχόμενο να υπάρχει
και ως HTML.

## Έλεγχος πριν την παράδοση

1. `node build/build.mjs` — καμία προειδοποίηση για placeholders.
2. Πλοήγηση με μόνο το `Tab` σε αρχική, υπηρεσία και επικοινωνία.
3. Zoom browser στο 200% (`Cmd/Ctrl` + `+`) — καμία οριζόντια κύλιση.
4. Έλεγχος με screen reader (VoiceOver: `Cmd+F5`).
5. Lighthouse → Accessibility (στόχος 100).
